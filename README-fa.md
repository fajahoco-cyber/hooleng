# ساخت اپ اندروید «دفتر مرسولات» با GitHub

این پروژه فایل‌های سایت را از روی هاست خودت می‌گیرد و با آن یک APK می‌سازد که:
- بدون اینترنت باز می‌شود (فایل‌ها داخل خود اپ هستند)،
- اسکنر بومی گوگل (ML Kit) دارد: فوکوس خودکار، چراغ، زوم و اسکن پیوسته،
- همان همگام‌سازی آفلاین را دارد (صف، ارسال به سایت، همگام‌سازی خودکار).

## ۱) آماده‌سازی هاست (یک‌بار)
1. فایل `htaccess-cors.txt` را باز کن و محتوایش را **بالاترین قسمت** فایل `.htaccess` سایت بچسبان (قبل از بقیه‌ی خط‌ها).
2. فایل‌های جدید وب را آپلود کن: `app.js` و `sw.js` (نسخه‌ی r18 به بعد)، `sync.php`، `cod.php`، `cod.html`، `offline.html`، `manifest.webmanifest`، `icon-192.png`، `icon-512.png`. دسترسی همه‌ی فایل‌ها غیر از `.php` را 644 بگذار.
3. تست: `سایت/sync.php?a=ping` باید پاسخ `{"success":false,"message":"نیاز به ورود"}` بدهد.

## ۲) ساخت مخزن در GitHub (یک‌بار)
1. در github.com حساب بساز و وارد شو.
2. **New repository** بزن، یک اسم بگذار (مثلاً `parcel-app`) و حتماً **Private** را انتخاب کن (چون بعداً کلید امضا در آن ذخیره می‌شود). بعد Create.
3. در صفحه‌ی مخزن: **uploading an existing file** را بزن و **همه‌ی فایل‌های همین پوشه** (`package.json`، `capacitor.config.json`، `.gitignore`، پوشه‌ی `scripts` و پوشه‌ی `.github`) را بکش و رها کن. بعد **Commit changes**.
   - اگر پوشه‌ی `.github` (چون با نقطه شروع می‌شود) آپلود نشد: **Add file ← Create new file** را بزن، اسم فایل را دقیقاً `.github/workflows/build-apk.yml` بنویس و محتوای فایل `build-apk.yml` را داخلش بچسبان.
4. **Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**
   - Name: `SITE_URL`
   - Value: آدرس سایتت با اسلش آخر، مثلاً `https://hooleng.ir/`

## ۳) اولین ساخت
1. تب **Actions** ← **Build Android APK** ← **Run workflow**.
2. حدود ۸ تا ۱۵ دقیقه صبر کن. اگر قرمز شد، روی ساخت کلیک کن، متن خطای مرحله‌ی قرمز را کپی کن و برای من بفرست.
3. اگر سبز شد، پایین صفحه‌ی همان ساخت در بخش **Artifacts** دو فایل هست:
   - `parcel-office-apk` ← فایل APK
   - `SAVE-THIS-keystore` ← **کلید امضا** (فقط بار اول ساخته می‌شود)

## ۴) ذخیره‌ی کلید امضا (خیلی مهم، فقط بار اول)
بدون این کار، دفعه‌ی بعد APK با کلید دیگری امضا می‌شود و روی نسخه‌ی قبلی نصب نمی‌شود.
1. `SAVE-THIS-keystore` را دانلود و باز کن. دو فایل دارد.
2. **Settings ← Secrets and variables ← Actions ← Secrets ← New repository secret** و سه تا بساز:
   - `KEYSTORE_B64` ← کل متن داخل فایل `KEYSTORE_B64.txt`
   - `KEYSTORE_PASSWORD` ← مقداری که در `SECRETS_TO_SAVE.txt` جلوی `KEYSTORE_PASSWORD=` است
   - `KEY_ALIAS` ← مقدار جلوی `KEY_ALIAS=` (معمولاً `parcel`)
3. فایل‌های دانلودشده را در جای امن نگه دار (مثلاً دو نسخه) و جای دیگر منتشر نکن.

## ۵) نصب روی گوشی
1. فایل APK را به گوشی منتقل کن (روبیکا، کابل یا ...) و باز کن.
2. گوشی «نصب از منبع ناشناس» را می‌خواهد؛ اجازه بده. اگر Play Protect هشدار داد، «Install anyway» را بزن (چون اپ را خودت ساخته‌ای).
3. اپ را باز کن، با رمز سایت وارد شو، اجازه‌ی دوربین را بده.
4. در «کار آفلاین» دکمه‌ی «همگام‌سازی» را بزن تا فهرست مرسولات روی گوشی بیاید.

## ۶) بروزرسانی اپ
- تغییر فایل‌های سایت (مثلاً `app.js` جدید): بعد از آپلود روی هاست، دوباره **Run workflow** بزن و APK جدید را روی قبلی نصب کن (اطلاعات گوشی پاک نمی‌شود، چون کلید امضا همان است).
- ارسال اطلاعات به سایت و دریافت فهرست جدید نیاز به ساخت دوباره ندارد؛ از دکمه‌ی «همگام‌سازی» یا حالت خودکار انجام می‌شود.

## عیب‌یابی کوتاه
- `SITE_URL is not set` ← مرحله‌ی ۲-۴ را انجام نداده‌ای.
- `FAIL index.html` یا `FAIL dashboard.html` در مرحله‌ی دانلود ← آدرس سایت اشتباه است یا فایل 403 می‌دهد (دسترسی 644).
- اپ باز می‌شود ولی ورود خطای شبکه می‌دهد ← بلوک CORS در `.htaccess` اضافه نشده یا ماژول `mod_headers` هاست فعال نیست.
- دوربین بومی باز نمی‌شود ← اجازه‌ی دوربین برای اپ در تنظیمات گوشی را بده.
